Machine Learning Insights

Model Performance

The evaluated machine-learning models achieved approximately 69% accuracy on the temporal 2018 test set, compared with a 56.29% majority-class baseline.

The results indicate that the tested models captured predictive patterns beyond simply predicting the majority class.

XGBoost Precision

XGBoost achieved 81.64% precision on the temporal test set.

This metric describes the proportion of orders predicted as late that were actually late in the test data.

Explainable AI Insight

SHAP analysis of the trained XGBoost model identified shipping mode and order type among the strongest model-level feature groups in the analysis.

SHAP explains how features contributed to individual model predictions. These contributions describe model behavior and should not be interpreted as causal relationships.

Business Considerations

1. Monitor Shipping Mode Performance

The substantial difference in observed late-delivery rates across shipping modes suggests that shipping-mode performance should be monitored regularly using operational delivery data.

2. Use Predictive Risk Scoring

The machine-learning model can be used to flag orders with elevated predicted late-delivery probability so that they can receive additional operational attention.

3. Combine Predictions with Explainability

SHAP explanations can provide feature-level context for individual predictions, making the prediction system easier to inspect and interpret.
